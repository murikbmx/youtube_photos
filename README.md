# morphe-repack

Собирает root-модуль (KernelSU / Magisk) из APK, пропатченного вручную в Morphe Manager.
Модуль устроен так же, как в [morphe-module](https://github.com/murikbmx/morphe-module), и ставится поверх него
(тот же id модуля).

Поддерживаются YouTube и Google Photos (список в `apps.sh`).

## Как пользоваться

1. Пропатчите приложение в Morphe Manager. **Патч GmsCore support (MicroG) должен быть отключён**:
   он меняет имя пакета, и такой APK не подойдёт для модуля. Настройки Morphe (качество, логотип и т.д.)
   выставляются потом в самом приложении.
2. Загрузите получившийся APK в релиз **input** этого репозитория. Имя файла любое.
   Если релиза ещё нет, первый запуск workflow создаст его.
3. Оригинал той же версии:
   - ничего не делать, если он есть в релизе `stock-apks` репозитория morphe-module;
   - иначе загрузите его в релиз **input** с именем `<пакет>-<версия>-arm64-v8a.apk`
     (или `.apkm` для split-архива), например `com.google.android.youtube-21.30.216-arm64-v8a.apkm`.
4. Actions → **Repack module** → Run workflow, выберите приложение.
   Поле с именем пропатченного APK можно не заполнять: возьмётся самый новый APK нужного приложения.

На выходе новый релиз с zip модуля. Автообновление модуля в root-менеджере после установки этой сборки
смотрит на этот репозиторий (ветка `update`), а не на morphe-module.

## Что делает сборка

- проверяет, что пропатченный APK — нужное приложение без смены пакета, а оригинал той же версии
  и подписан Google;
- вырезает из пропатченного APK нативные библиотеки (модуль берёт их из оригинала при установке),
  выравнивает (zipalign) и подписывает его;
- упаковывает модуль: `base.apk` (пропатченный) и `stock/base.apk` (оригинал, ставится, если в системе другая версия).

## Локально

```
./repack.sh YouTube patched.apk [stock.apk|stock.apkm]
```

Нужны Java 21, `jq`, `zip`, `aapt2` и `zipalign` из Android SDK build-tools
(через `ANDROID_HOME` или переменные `AAPT2` / `ZIPALIGN`).
